# Contributing

Contributions are welcome.

This repository is intentionally lightweight. Please keep the Skill practical and focused on architecture decisions before coding.

## Good contributions

- Add realistic examples
- Improve the architecture checklist
- Add clearer output formats
- Add better risk categories
- Add examples for specific product types

## Avoid

- Turning this into a large framework
- Adding unnecessary scripts
- Making the Skill too theoretical
- Overfitting to one tech stack

## Pull request guideline

Please explain:

1. What problem the change solves
2. How it improves architecture decision-making
3. Whether it increases or reduces complexity
