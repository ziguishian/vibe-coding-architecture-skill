# Installation

This repository can be used in three ways.

## 1. Use as a reference repository

Read `SKILL.md`, `references/`, and `examples/` before starting an AI coding project.

This is the simplest mode. You do not need to install anything.

## 2. Copy into a Codex Skill directory

Copy the repository folder into your Codex Skill directory according to your local Codex setup.

The important file is:

```text
SKILL.md
```

Codex uses the Skill description to decide when this Skill should be triggered.

## 3. Use inside a project as a pre-architecture document

You can place this repository beside a product project and use it as the architecture planning reference before implementation.

Recommended flow:

1. Describe the product idea.
2. Ask for architecture planning.
3. Review the generated Build Brief.
4. Only then ask Codex to implement.

## Notes

This repository does not require npm install, pip install, build scripts, or code generation scripts.
