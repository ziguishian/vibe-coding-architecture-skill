# Localization

This repository maintains five README files:

- `README.md`: default Simplified Chinese README
- `README.en-US.md`: English README
- `README.zh-CN.md`: Simplified Chinese README
- `README.ja-JP.md`: Japanese README
- `README.ko-KR.md`: Korean README

## Consistency rules

The following information must remain consistent across all README files:

- Skill name
- One-line positioning
- Core philosophy
- File structure
- Usage method
- Supported project types
- Contribution method
- License
- Star History section
- Links to other language README files

## Update rules

When feature descriptions change, update all README files together.

Translations do not need to be word-for-word identical. They should be natural in each language while preserving the same meaning.

## Chinese style note

The Chinese README may be more native to Chinese creators, indie hackers, and AI builders, but it should remain practical and not become pure marketing copy.
