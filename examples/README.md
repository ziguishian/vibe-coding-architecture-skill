# Examples

These examples show how `vibe-coding-architecture-skill` turns product ideas into beginner-friendly architecture plans.

Each example includes:

- User original input
- How the Skill understands it
- Key follow-up questions
- Recommended architecture
- Mermaid diagram
- MVP scope
- Data model
- API Contract
- Risks
- Codex Build Brief

Use them as references, not rigid templates.
